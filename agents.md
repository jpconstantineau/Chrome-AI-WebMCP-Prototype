# Agents

This repository uses the following guidance files:

- `INTENT.md` explains the product intent and expected prototype behavior.
- `DESIGN.md` defines the minimal user interface direction and visual goals.

When making changes, agents should read both files before updating implementation details. Just as the ponytail skill indicates, keep the app minimal, static, and browser-only, and do not introduce server-side dependencies or backend APIs.  Do not require any build steps.

The prototype should remain simple enough to support experiments with local AI, WebMCP, and PWA behaviors in Chrome without needing a hosted service.
