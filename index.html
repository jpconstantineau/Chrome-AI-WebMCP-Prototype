Prompt API setup · WebMCP setup

Chrome setup instructions

Use desktop Chrome with HTTPS or localhost. If WebMCP is missing, open chrome://flags/#enable-webmcp-testing, select Enabled, relaunch Chrome, then reload this page.

If the Prompt API is missing, update Chrome and check its Prompt API support. Experimental builds may expose chrome://flags/#prompt-api-for-gemini-nano (or a Prompt API flag) and chrome://flags/#optimization-guide-on-device-model; enable the available feature flags and relaunch. Flag names vary by Chrome version.

If the local model is unavailable, check the supported desktop operating system, free disk space, hardware and Chrome policy requirements in the linked Prompt API guide. Use an unmetered connection for the initial download. Inspect chrome://on-device-internals for model status.

chrome://flags/#prompt-api-tool-use is optional for experimental native model proposals. The default JSON bridge works without it. Chrome does not expose flag values to this page; these checks detect available APIs, not the cause of a missing API.
